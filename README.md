# تهاني زواج عبد الله

تجربة عربية بسيطة ومهيأة للجوال لضيوف زواج عبد الله يحيى الحِدريتي. يصل الضيف من رمز QR، يكتب اسمه وتهنئته، يختار أحد ثلاثة تصاميم بطاقة ويعاينه بحرية، ثم يرسل — فتُحفظ التهنئة وتصميمها معًا في Supabase. بعدها يمكنه حفظ البطاقة نفسها كصورة أو مشاركتها من جواله.

## نطاق النسخة الحالية

- نموذج قصير للاسم والتهنئة.
- معاينة حرة لثلاثة تصاميم بطاقة ثابتة قبل الإرسال.
- حفظ التهنئة وتصميمها معًا في Supabase بإدخال واحد، مع إعادة محاولة تلقائية عند ضعف الشبكة.
- شاشة تأكيد بعد الإرسال، مع حفظ أو مشاركة البطاقة نفسها كصورة.
- صفحة `/admin` محمية بكلمة مرور لتصفح التهاني كقائمة أو كبطاقات مصممة.
- توليد الصورة بالكامل داخل المتصفح باستخدام Canvas.
- مشاركة ملف الصورة عبر Web Share API عندما يدعم الجهاز ذلك.
- معاينة الصورة بالحجم الكامل وحفظها في الصور بالضغط المطوّل كحل بديل.
- RTL كامل وتصميم mobile-first.

لا يوجد خادم تطبيق: الموقع ثابت بالكامل ويتحدث مع Supabase من المتصفح مباشرة. لا توجد حسابات للضيوف ولا تحليلات.

## التقنية

- Next.js (App Router + static export)
- React + TypeScript
- Tailwind CSS
- Supabase (Postgres + Storage + Auth)
- Browser Canvas + Web Share APIs
- نشر متوافق مع Vercel

تستخدم أوامر المشروع وضع Webpack المدمج في Next.js لأن بيئة التطوير الحالية تمنع المنفذ الداخلي الذي يستخدمه Turbopack أثناء معالجة Tailwind. لا يغيّر ذلك بنية الموقع الثابت أو طريقة نشره.

## التشغيل محليًا

المتطلبات: Node.js 20.9 أو أحدث وnpm.

```bash
npm install
npm run dev
```

ثم افتح `http://localhost:3000`.

أوامر التحقق:

```bash
npm run lint
npm run typecheck
npm test
npm run build
```

أو شغّلها كلها عبر `npm run check`.

## إعداد Supabase

1. أنشئ مشروع Supabase، ثم نفّذ ملفات `supabase/migrations/` بالترتيب في SQL Editor. تنشئ الملفات جدول `wishes` وسياسات الحماية، وتضيف عمود تصميم البطاقة.
2. انسخ `.env.example` إلى `.env.local` واملأ القيمتين من Project Settings > API:

```bash
cp .env.example .env.local
```

3. أنشئ حساب المدير الوحيد في Authentication > Users بنفس البريد الموجود في `adminEmail` داخل `src/config/wedding.ts`، ثم عطّل التسجيل العام من إعدادات Auth.

نموذج الحماية بسيط: الضيف يملك مفتاحًا عامًا يسمح له بالإضافة فقط، ولا يستطيع قراءة أو تعديل أو حذف أي تهنئة. القراءة متاحة فقط لجلسة مسجلة الدخول. الحدود القصوى للاسم والنص مفروضة في قاعدة البيانات نفسها لأن النموذج في المتصفح غير موثوق.

## إعداد بيانات الزواج

كل البيانات العامة القابلة للتعديل موجودة في:

```text
src/config/wedding.ts
```

رقم واتساب يُكتب بالصيغة الدولية أرقامًا فقط، مثل `9665XXXXXXXX`، من دون `+` أو مسافات. الحقل `adminEmail` هو حساب Supabase الذي يدخل به عبد الله إلى `/admin`.

## خط ثمانية المحلي

توجد ملفات WOFF2 المطلوبة داخل:

```text
public/fonts/thmanyah/
```

الملفات المستخدمة حاليًا:

- `ThmanyahSans-Regular.woff2`
- `ThmanyahSans-Medium.woff2`
- `ThmanyahSans-Bold.woff2`
- `ThmanyahSerifDisplay-Bold.woff2`
- `ThmanyahSerifText-Regular.woff2`
- `ThmanyahSerifText-Medium.woff2`

راجع `public/fonts/thmanyah/README.md`. تستخدم الواجهة نسخة Sans، بينما تستخدم البطاقات Serif Display للاسم وSerif Text للتهنئة. يحمل مولّد Canvas العائلات نفسها قبل رسم الصورة.

تُعرّف الخطوط عبر `@font-face` محلي بدل CDN أو أسماء `next/font` المولّدة، لأن مولّد Canvas يحتاج أسماء عائلات ثابتة حتى تطابق صورة PNG المعاينة الظاهرة.

## البناء والنشر

```bash
npm run build
```

ينتج Next.js موقعًا ثابتًا في `out/`. على Vercel اربط المستودع واستخدم إعدادات Next.js الافتراضية، مع إضافة متغيري البيئة نفسيهما إلى إعدادات المشروع.

## القيود الحالية

- المشاركة المباشرة للملفات تعتمد على دعم الجهاز وHTTPS. عند عدم الدعم تبقى البطاقة ظاهرة ويمكن تكبيرها وحفظها بالضغط المطوّل.
- لا يستطيع المتصفح حفظ الصورة مباشرة داخل ألبوم الصور؛ لذلك توفر صفحة المعاينة تكبيرًا بالحجم الكامل وتعليمات للضغط المطوّل واختيار «حفظ الصورة» أو «إضافة إلى الصور».
- تُرفق نافذة المشاركة ملف PNG لكنها لا تحدد مستلمًا؛ لذلك توفر صفحة البطاقة زر نسخ رقم عبد الله.
- مشاركة iPhone Safari وAndroid Chrome يجب اختبارها على أجهزة فعلية قبل ليلة الزواج.
- عند اختيار واتساب من نافذة مشاركة البطاقة، يرسل الموقع الصورة ونص التهنئة معًا. ظهور النص كتعليق للصورة يعتمد على نظام الجهاز ونسخة واتساب؛ لا يمكن للموقع فرض فتح واتساب أو الإرسال تلقائيًا.
- التهاني غير قابلة للتعديل أو الحذف من الموقع؛ الحذف يتم من لوحة Supabase عند الحاجة.
- مفتاح Supabase العام يظهر في ملفات الموقع بحكم التصميم، والحماية الفعلية من سياسات Row Level Security. لا يوجد حد لعدد الإرسالات، وهو مقبول لمناسبة تستمر ليلة واحدة.
